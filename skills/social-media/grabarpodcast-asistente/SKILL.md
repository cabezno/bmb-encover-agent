## RAG (Retrieval-Augmented Generation) — Mayo 2026

Se creó un índice RAG local con ChromaDB + sentence-transformers (all-MiniLM-L6-v2) con toda la data del negocio extraída de la web.

**Ubicación del índice:** `/tmp/grabarpodcast_chroma`
**Colección:** `grabarpodcast` (79 chunks)
**Datos indexados:** Tienda (144 productos con precios), categorías Podcast/Streaming/Packs (paginadas), páginas de WordPress (inicio, contacto, carrito, finalizar-compra, términos), homepage

**Cómo usarlo:**
```python
from chromadb.utils import embedding_functions
import chromadb
ef = embedding_functions.SentenceTransformerEmbeddingFunction(model_name="all-MiniLM-L6-v2")
client = chromadb.PersistentClient(path="/tmp/grabarpodcast_chroma")
col = client.get_collection("grabarpodcast", embedding_function=ef)
results = col.query(query_texts=["consulta del cliente"], n_results=5)
```

## PITFALLS
- Los LIDs de WhatsApp no coinciden con números de teléfono. Contactos conocidos pueden aparecer como no registrados.
- Los `primer_mensaje` en contactos deben estar vacíos. El agente responde dinámicamente.
- No linkear precios en paso 1 (efectivo). Solo linkear en paso 3 (web/cuotas).
- El cupón se llama GRABAR2026, vale 20% OFF, no 10%.
- **WHATSAPP_ALLOWED_USERS=* ES OBLIGATORIO en .env para que clientes puedan escribir.** Si está seteado a una lista concreta, cualquier otro número es bloqueado por el bridge con ignored: allowlist_mismatch y el agente nunca ve el mensaje. * permite todos los números. group_policy:disabled + auto-clasificación + reenvío al dueño mitigan el spam.
- **WhatsApp calls: NO se pueden contestar.** Si un cliente quiere llamar al estudio, Hermes no puede atender la llamada. WhatsApp usa WebRTC cifrado fuera del alcance de cualquier bridge open source. Alternativa: que el cliente escriba por WhatsApp o use el formulario de contacto en la web.
- **Respuestas de voz en WhatsApp:** Funcionan con Gemini 3.1 Flash TTS + Baileys bridge, pero el audio debe ser OGG Opus con `ptt=true`. El sistema actual rechaza MP3 para WhatsApp voice (ver skill `whatsapp-voice-reply-config`).
- **Targets de cron y envíos:** NO usar números de teléfono. Usar el nombre de contacto exacto del bridge (ver `references/contactos-whatsapp-bridge.md`).
- **Envío de archivos de audio por WhatsApp:** `send_message` de Hermes NO soporta MEDIA para WhatsApp. Para enviar audio (ej: pruebas TTS), llamar directo al bridge en `http://127.0.0.1:3000/send-media` con `mediaType: "audio"`. Ver `references/envio-audio-whatsapp-bridge.md`.
- **RAG pipeline disponible (Mayo 2026):** Se construyó un pipeline completo S2S+RAG para GrabarPodcast. Ver `references/pipeline-s2s-rag-grabarpodcast-mayo2026.md`. Incluye índice ChromaDB con 79 chunks de la web, whisper→rag→deepseek→tts. Índice en `/tmp/grabarpodcast_chroma/`.
- **CosyVoice 3 y XTTS-v2 fueron ELIMINADOS (Mayo 18, 2026):** Por pedido del usuario. Ambos producían español de España, no latinoamericano. Ver skill `local-tts-conversacional` para modelos disponibles.
- **⚠️ /tmp/ es VOLÁTIL en WSL:** El RAG index en `/tmp/grabarpodcast_chroma/` y cualquier modelo descargado en `/tmp/` se pierde al reiniciar sesión o WSL. Para datos persistentes, usar `/opt/grabarpodcast/` u otro directorio fuera de `/tmp/`.
